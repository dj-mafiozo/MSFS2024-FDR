# Portable installation

Extract the entire unencrypted ZIP and run MSFS2024-FDR.exe. Keep DLLs, fonts, Assets and help beside it. User data lives in %LocalAppData%\MSFS24-FDR. MSFS24-FDR-Setup.exe only displays a development notice and exits. It does not install, update or remove anything; update checks are disabled. Download later versions manually. The optional MSFS24-FDR-Bridge folder can be copied into Community using the included instructions.
