# Portable Installation

Das vollständige ZIP ohne Passwort entpacken und MSFS2024-FDR.exe starten. DLLs, Fonts, Assets und Hilfe zusammenlassen. Benutzerdaten liegen unter %LocalAppData%\MSFS24-FDR. MSFS24-FDR-Setup.exe zeigt nur einen Entwicklungshinweis und endet. Es installiert, aktualisiert oder entfernt nichts; Update-Prüfungen sind deaktiviert. Neue Versionen manuell herunterladen. Den optionalen MSFS24-FDR-Bridge-Ordner gemäß Paket-Anleitung nach Community kopieren.
