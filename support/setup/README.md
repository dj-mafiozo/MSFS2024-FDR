# Instalacja portable

Rozpakuj cały ZIP bez hasła i uruchom MSFS2024-FDR.exe. Zachowaj DLL, fonty, Assets i pomoc. Ustawienia i nagrania są w %LocalAppData%\MSFS24-FDR. Dołączony MSFS24-FDR-Setup.exe wyświetla tylko informację o trwających pracach i kończy działanie. Nie instaluje ani nie aktualizuje programu; sprawdzanie aktualizacji jest wyłączone. Nowe wersje pobiera się ręcznie. Opcjonalny folder MSFS24-FDR-Bridge można skopiować do Community zgodnie z instrukcją w paczce.
