# Instalación portable

Extraiga todo el ZIP sin contraseña y ejecute MSFS2024-FDR.exe. Mantenga DLL, fuentes, Assets y ayuda junto al programa. Los datos están en %LocalAppData%\MSFS24-FDR. MSFS24-FDR-Setup.exe solo muestra un aviso de desarrollo y termina. No instala, actualiza ni elimina nada; las comprobaciones están desactivadas. Descargue las versiones nuevas manualmente. Copie el puente opcional MSFS24-FDR-Bridge a Community según las instrucciones incluidas.
