# Interface translations

Interface translations are generated automatically and may contain errors, especially in aviation terminology. They have not had a complete native-speaker review. If you speak one of these languages and find a mistake, please report it on GitHub.

[GitHub Issues — MSFS2024-FDR](https://github.com/dj-mafiozo/MSFS2024-FDR/issues)

Include the language and locale code, current wording, suggested correction and its location in the application. A screenshot and brief aviation context are helpful. You can also submit a pull request for `translations/MSFS2024-FDR.i18n`. Preserve identifiers, units, parameter names and formatting placeholders such as `%s` and `%d`. Raw FMC, METAR and OFP content is not translated.
