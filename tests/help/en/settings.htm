Settings

Configure recording interval, language and analysis provider. Codex, Gemini and Ollama need their own configuration; Ollama models are listed from the local service.

Panel sizes are remembered. Restore defaults resets layout. SimBrief matches a plan to the recording; older plans require the optional allowance and matching available data.

Display units

In Settings → Units choose a target for each source unit, e.g. ft → m, lb → kg, US gal → l. Keeping the source unit disables conversion. Charts (curves, scales, cursor) and the parameter inspector update, including detached windows. Stored data and analysis inputs retain their original units. Unknown SDK units are never guessed.
