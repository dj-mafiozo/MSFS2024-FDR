@overview|Erste Schritte
Wählen Sie zunächst Aufnahme oder Analyse. Aufnahme benötigt MSFS 2024; Dateianalyse funktioniert offline. Behalten Sie die Paketstruktur bei, starten Sie MSFS24-FDR.exe und prüfen Sie Sprache und Status. Laden Sie das Flugzeug und verlassen Sie die Vorbereitung mit Ready for flight.
Für Wiedergabe wählen Sie links einen abgeschlossenen Flug und lösen bei Bedarf einzelne Ansichten. Vergleichen Sie denselben Zeitpunkt auf Karte, PFD und Daten. Plan/OFP verwenden die anonymisierte Schleife EPLL.25 ADOX2W SOXE2T LL501 ILSZ.25 EPLL.25; Telemetrie ist synthetisch.
MSFS24-FDR zeichnet Microsoft Flight Simulator 2024 auf und spielt dessen Daten ab. MSFS 2020, FSX und Prepar3D werden nicht unterstützt. Die Instrumente sind Analyseanzeigen, keine Simulatorsteuerung.
Erste Aufnahme :: Vollständiges Win64-Archiv entpacken, EXE starten, Flug in MSFS 2024 laden und Ready for flight wählen. Vor manueller/automatischer Aufnahme die Verbindung abwarten.
Wiedergabe :: Abgeschlossenen Flug links auswählen. Karte, Diagramme, Instrumente und Datenseiten verwenden dieselbe aufgezeichnete Zeit.
Benutzerdaten :: Einstellungen, Index, Aufnahmen und Protokolle liegen in %LocalAppData%\MSFS24-FDR. Den gesamten Ordner einschließlich Recordings sichern; Programmdateien getrennt ersetzen.
Offline :: Gespeicherte Daten/Pläne/Nachrichten/Karten funktionieren ohne MSFS. Neue Kartenkacheln, Wetter, SimBrief und Cloud-KI brauchen die jeweilige Netzwerkverbindung.
Hilfe :: F1 öffnet das Thema des aktiven Bereichs. Inhaltsbaum und CHM-Suche verwenden; andere Oberflächensprachen greifen auf Englisch zurück.
@recordings|Aufnahmebibliothek, Import und Wiederherstellung
Sichern Sie die Quelle vor Import einer alten Datenbank oder einzelner MFZR. Migration erstellt je Flug eine Datei; der Index speichert Metadaten und relativen Pfad. Fehlende Dateien blenden den Flug aus, ohne den Eintrag zu löschen. Prüfen Sie den Speicherort. Text- und Gruppenfilter wirken gemeinsam.
Der Baum gruppiert ICAO-Flugzeugtyp, Abflug-ICAO, Jahr und lokalisierten Monat; neueste Flüge zuerst. Fehlende Dateien löschen keine Indexmetadaten.
Suche / Gruppen :: Text- und Gruppenfilter wirken zusammen. Zum Zurücksetzen leeren. Ein Ordner ist keine einzelne Aufnahme.
Öffnen / Aktualisieren :: Datenbank/Index auswählen beziehungsweise Bibliothek neu laden und abgelegte .mfzr erkennen.
Import :: Einzelne .mfzr, alte flight_data.db und ursprüngliche Qt-Datenbanken. Alte Flüge werden getrennte Dateien; Quellen bleiben erhalten, wiederholter Import erkennt vorhandene Einträge.
Legacy-Export :: Ein Flug mit den Feldern des ursprünglichen Recorders, ohne SDK/FMC/Wetter-Erweiterungen. Kein vollständiges Backup.
Gruppen / Metadaten :: Gruppen erstellen, umbenennen, löschen und mit OK zuweisen. Fluginformationen bearbeiten die angebotenen Metadaten; Telemetrie bleibt separat.
Flug löschen :: Bestätigung entfernt Datei und Indexeintrag. Laufende Aufnahme zuerst stoppen. Dies versteckt nicht nur eine Zeile.
Wiederherstellung :: Nach einem Absturz beim Start bestätigen. Das Ergebnis kann unvollständig/beschädigt sein; wertvolle Dateien vorher sichern.
Einzelvorschau :: EXE mit bestehendem .mfzr-Pfad starten: nur dieser Flug, ohne Bibliothek, Verwaltungs-/Aufnahmeaktionen oder SimConnect.
@recording|Simulatorflug aufzeichnen
Automatische Aufnahme benötigt den tatsächlichen Flugbeginn, nicht nur Verbindung oder Vorbereitung. Sitzungsende schließt und finalisiert; finalizing ist noch nicht completed. Kürzere Intervalle erhöhen Last und Datenmenge, nicht zwingend die SDK-Publikationsrate. Sichern Sie nach CTD die wiederherstellbare Datei.
Eine unterstützte MSFS-2024-Verbindung und ein bereiter Flug sind erforderlich; Vorbereitung oder AircraftLoaded allein reichen nicht.
Start / Stop :: Start beginnt die aktive Aufnahme. Stop finalisiert die Datei; vor Verschieben/Beenden warten. Aktive Dateien sind keine abgeschlossenen Flüge.
Automatisch :: Wartet auf den Flug nach Ready for flight und berücksichtigt Sitzungs-/Flugzeugereignisse. Nach CTD Status und Wiederherstellung prüfen.
Abtastintervall :: Millisekunden im Werkzeugfeld. Kleinere Werte erzeugen mehr Daten/Last. Neue Aufnahmen speichern den Wert, ältere verwenden abgeleiteten Abstand oder 500 ms.
Flugzeugdaten :: Abonnements folgen Typ und Triebwerken. Ein anderer Renderer erzeugt keine fehlenden SDK/L-Variablen.
Status :: recording aktiv, finalizing Abschluss, completed normal beendet; interrupted/error prüfen. Recording kennzeichnet einen nicht verfügbaren aktiven Eintrag.
Offline :: Fehlende MSFS-Verbindung beeinträchtigt eine geladene Offline-Aufnahme nicht.
@workspace|Arbeitsbereich, Andocken und Fenster
Passen Sie zuerst Bibliothek und Datenbreite, dann Karten-, Diagramm- und Instrumenthöhe mit Splittern an. Proportionen bleiben beim Vergrößern erhalten; Instrumente behalten ihre Geometrie und können Ränder zeigen.
Ziehen Sie Register aus dem Panel oder auf ein Andockziel. Die Fensteraktion wechselt Zustand und Symbol. Schließen stellt den Inhalt zurück. Ein leerer Host soll einklappen; Zustand und Geometrie werden pro Ansicht gespeichert.
Karte, Diagramme, Instrumente und Zeit sind zentral; Bibliothek links, Datenseiten rechts. Splitter verteilen den Platz.
Separates Fenster :: Die Fensteraktion verschiebt denselben Frame und ändert das Symbol; Daten/Zeit bleiben synchron.
Registerkarten :: Kopf herausziehen, an Registerleiste/Randziel andocken. Schließen bringt die Karte zum Ausgangsbereich zurück.
Instrumentfenster :: PFD und EICAS/ECAM können gemeinsam in einem schwebenden Host liegen. Andockziele verwenden.
Größe :: Panelproportionen und Instrumentseitenverhältnis bleiben erhalten; Ränder verhindern Verzerrungen.
Speichern / Reset :: Zustand, Position und Größe jedes Fensters werden gespeichert. Leere Hosts klappen ein. Standardlayout in Einstellungen stellt Anordnung, nicht Flugdaten, zurück.
@playback|Wiedergabe und aufgezeichnete Zeit
1x folgt der Aufnahmezeit, nicht einem Messwert je Timeraufruf. Interpolation glättet kontinuierliche Werte und Winkel, Schalter bleiben sprunghaft. Pausieren Sie zur genauen Auswahl. Stop kehrt zum Anfang und 1x zurück. Normale Zeitsprünge sind 30 Sekunden, Ghost-Sprünge 10.
Normale Wiedergabe steuert die Analyse, nicht ein Simulatorflugzeug; Ghost ist unabhängig.
Start / Pause :: Karte, Diagramme, Instrumente, FMC und Nachrichten folgen demselben Cursor.
Stop :: Stoppt, springt zum Anfang und setzt 1x.
Sprünge :: Anfang/Ende zum ersten/letzten Punkt; Zurück/Weiter um 30 Sekunden innerhalb der Aufnahme.
Geschwindigkeit :: 0.125, 0.25, 0.5, 0.75, 1, 2, 4, 8 oder 16x; Anzeige zeigt die Auswahl. Fehlende Samples werden nicht ergänzt.
Schieberegler / Maus :: Direkte Zeitauswahl. Diagramm-Hover ist während laufender Wiedergabe deaktiviert; zur Inspektion pausieren.
Interpolation / ATC :: Kontinuierliche Werte können interpolieren, Schalter bleiben diskret. Die letzte ATC-Zeile erscheint etwa 30 aufgezeichnete Sekunden; Lücken sind keine gültigen Nullen.
@ghost|Ghost-Flugzeug in MSFS 2024
Laden Sie einen Flug in MSFS 2024 und wählen Sie die Aufnahme. Ghost hat eigene Verbindung/Thread und ist von Analysewiedergabe getrennt. Stoppen Sie vor Datei-/Sitzungswechsel. AIG/FSLTL benötigen installierte Community-Modelle; VMR installiert nichts. Ersatzmodelle können weniger Animationen anbieten.
Ein visuelles KI-Flugzeug, nicht das Benutzerflugzeug; die ursprüngliche Addon-Avionik wird nicht ausgeführt.
Start / Pause / Stop :: Benötigt geladenen MSFS-Flug und SimConnect. Stop entfernt das Objekt; vor Sitzungs-/Aufnahmewechsel stoppen.
Zurück / Weiter :: Ghost um jeweils 10 Sekunden versetzen, unabhängig von normalen 30-Sekunden-Sprüngen.
Aktualisierung :: 5–60 Hz, Standard 30. Mehr Aktualisierungen erhöhen weder ursprüngliche Datendichte noch garantiert die Darstellungsleistung.
Modelle :: Bestes installiertes AIG/FSLTL-Typ-/Livery-Match, sonst Standard-KI. Modell muss tatsächlich in Community vorhanden sein.
VMR :: Optional FSLTL_Rules.vmr; leer bedeutet automatisch. Regeln installieren keine Modelle.
Animationen :: Position, Lage, Fahrwerk/Klappen/Spoiler, Steuerflächen, Motoren, Licht und Umkehrschub hängen von Aufnahme und beschreibbaren Modelleingängen ab.
@map|Karte und Routenebenen
OpenStreetMap ordnet Positionen dem Gelände zu. Die Spur enthält Messungen, Magenta den Plan. Überlappende Abschnitte brauchen keine doppelte Linie; Punkte und Einschränkungen bleiben sichtbar. Verbindungslinien sind keine metergenaue Messung.
Die Beispielrunde führt von EPLL 25 über ADOX2W, ADOXO, SOXER, SOXE2T und LL501 zum ILS Z 25. Punkte illustrieren die Funktion und ersetzen keine aktuellen Karten. Ziehen verschiebt, Mausrad zoomt, Einpassen stellt die Ausdehnung wieder her. Neue Kacheln benötigen Netz.
Tatsächliche Spur sind gemessene Positionen; Magenta ist der gespeicherte Plan.
Navigation :: Ziehen verschiebt, Mausrad/Tasten zoomen, Anpassen rahmt Daten ein. Übersicht zeigt Bibliotheksrouten.
Kacheln :: Online-Hintergrund umschalten. Cache kann offline funktionieren; fehlender Hintergrund bedeutet nicht fehlendes GPS.
Plan :: Wegpunktnamen und vorhandene Einschränkungen; deckungsgleiche Abschnitte ohne doppelte Linie.
Verfahren :: SID/STAR/Anflug nach EFB-Auflösung gespeichert. Fehlanflüge dunkelgrau; Holdings mit Parametern und schematischen Symbolen.
Nur Koordinaten :: Passender SimBrief-Plan kann bei AIRAC-Abweichung Namen ergänzen, aktualisiert aber keine Navigationsdatenbank.
Export :: PNG ist eine Abbildung, KML eine Spur für andere Programme; kein Ersatz für .mfzr.
@flight-plan|Flugplan, EFB und Verfahren
Planlesen und Navigation auflösen sind getrennt. EFB liefert zuerst Flughäfen und Verfahrensnamen; Facility-Abfragen ergänzen gespeicherte Geometrie und Einschränkungen. ADOX2W allein enthält keine vollständigen Koordinaten. SimBrief kann namenlose Punkte zuordnen, fehlende Einschränkungen werden nicht erfunden. Aufgelöste Routen funktionieren offline.
Die Seite zeigt den gespeicherten Plan, keinen FMS-Editor.
Erfassung :: Nach Flugbeginn EFB/SimConnect lesen, Facility-Daten für Verfahrensbeine/Positionen auflösen und speichern.
Flughäfen :: Abflug/Ziel können vor Motorstart bekannt sein. UNKNOWN bedeutet fehlende oder noch nicht aufgelöste historische Daten.
PLN-Import :: PLN zuweisen und Flughäfen/Quelle prüfen, bevor die Kartenebene interpretiert wird.
Beschränkungen :: Geschwindigkeit/Höhe/Position/Rolle nur soweit vorhanden; der Plan belegt keine ATC-Freigabe.
Offline :: Gespeicherte Snapshots brauchen keine neue Simulatorabfrage. Alte Texte/Punkte lassen Verfahren nicht immer vollständig rekonstruieren.
@charts|Diagramme und Parameterinspektion
Wählen Sie passende Größen: IAS, V/S und Nickwinkel für Aufsetzen oder N1/EGT/FF für Leistung. Nicht alle Parameter müssen gleichzeitig sichtbar sein. Die Reihenfolge wird im Auswahldialog festgelegt. Anzeigeeinheiten ändern keine Quelldaten.
Zeitcursor und Arbeitsbereich sind synchron.
Auswahl :: Konfiguration legt sichtbare Parameter/Reihenfolge fest; verfügbare Namen durchsuchen.
Zoom / Verschieben :: Zeitbereich verkleinern/vergrößern, darin verschieben; Gesamtansicht stellt die komplette Spanne her.
Cursor :: Hover sucht Zeit bei Pause, nicht während laufender Wiedergabe.
Einheiten / Lücken :: Anzeigeeinheiten ändern keine Samples. Auditierte Schaltertexte bleiben Cockpitbegriffe; unbekannte Werte numerisch. Eine fehlende Linie ist keine gemessene Null.
@chart-options|Diagramme auswählen und sortieren
Links stehen verfügbare Parameter, rechts nur die sortierte Diagrammauswahl. Suche filtert links; leeren Sie sie für andere Gruppen. Tasten und Ziehen zwischen Listen zeigen/verbergen Werte.

Verfügbare Parameter links, geordnete sichtbare Auswahl getrennt.
Suche :: Namensfragment suchen, leeren für alle Parameter; keine Löschung.
Anzeigen / Ausblenden :: Diagramm in die Darstellung aufnehmen oder entfernen, ohne Aufnahmeänderung.
Drag-and-drop :: Zwischen Listen zum Anzeigen/Ausblenden ziehen; nur akzeptierte Ziele wirken.
Reihenfolge :: Auf/Ab/Anfang/Ende oder Strg-Ziehen in der sichtbaren Liste; zwischen Zeilen einfügen.
OK / Abbrechen :: Auswahl übernehmen oder Dialogänderungen verwerfen.

@atc|ATC- und FSHud-Kommunikation

Historische Nachrichten; FSHud und MSFS-ATC sind getrennte Quellen.
