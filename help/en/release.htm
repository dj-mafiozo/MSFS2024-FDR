Portable releases and changelog

Extract the complete ZIP into one folder, retaining graphics, fonts and help subdirectories. Close the app before manual replacement. Settings/recordings remain in LocalAppData, but keep backups. Do not overwrite personal INI with the example. Setup is a notice-only stub, not an installer/uninstaller; automatic updating is disabled. Changelog groups releases, while full Build identifies diagnostics.
