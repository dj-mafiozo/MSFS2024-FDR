Recorded instrument displays

These are analysis reconstructions, not certified avionics or interactive cockpit controls.

Option / actionBehavior and limitations
Automatic kindThe recorded type/category selects analog GA, glass/classic, generic or a supported airliner frame. Debug override changes visualization, not aircraft identity.
Six-packAirspeed, attitude, altitude, turn/slip, heading and VSI use recorded data. Valid ILS LOC/GS and barometric setting appear when available.
ScalesAnalog VSI retains a stable recording/profile range. A converted text unit is distinct from a conventional feet-based altimeter mechanism.
Missing dataDashes preserve no-data versus real zero. Old flights cannot gain SDK states never captured.
RenderingAspect ratio and antialiasing work above/below 100%. Detached frames keep the same source and cursor.
