B38M EICAS: engines, fuel and configuration

This EICAS is dedicated to B38M. N1, EGT and N2 use analogue arcs with numeric readings. Fuel flow, oil and vibration appear below, with flap configuration and tank/total fuel alongside. Check units: fuel quantity in thousands of kg is not the same scale as flow in kg/h.

Valve, oil-pressure and engine annunciations use recorded data. An absent warning in an older file does not prove it was absent in the cockpit. This is not the final B736–B739 EICAS. Detach it separately or dock it beside the PFD in one window while retaining the shared replay cursor.
