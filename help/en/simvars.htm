Standard SimVar parameter catalog

This catalog is generated directly from the application’s numeric, Boolean and engine telemetry declarations. The demonstration chart dialog includes all these parameters, with engines 1–4. It documents FDR support, not every variable in Microsoft’s SDK. Addon SDK and GSX variables have separate catalogs.

IDs are stable internal FDR names; captions and units reflect application language/display settings. Actual recordings may contain fewer parameters according to aircraft, engine type and captured subscriptions. Piston-only variables are not forced onto jets. Adding a chart cannot recover values never recorded.

Use CHM search or the chart-dialog search to find a parameter. Select the required values, add them to the displayed list, set their order and confirm OK. Raw IDs help compare this catalog with Values and diagnostics.
