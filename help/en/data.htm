Values, events and takeoffs/landings

Values answers “what was the state at this instant”, Events “what was recorded”, while Takeoffs/Landings selects a contact. These are different views of one recording. Detach them to compare tables beside instruments. Values search does not filter the flight library; recording search does not remove parameters. Each view has its own child chapter.

Tabs describe the chosen recording and time, not the currently loaded live aircraft.

Option / actionBehavior and limitations
Values searchFilters readable captions and raw identifiers. Clear for all rows. Values follow the cursor.
Switch labelsAudited enums show UP/1/2/5 or RTO/DISARMED where appropriate. Cockpit terms intentionally stay untranslated. Unknown numbers remain numeric.
EventsInspect recorded event type/time as historical evidence.
ContactsSelect liftoff/touchdown to inspect weather or request analysis. Event time is not necessarily the beginning of rotation or flare.
MetadataFlight type/airport grouping is separate from measured telemetry and the current simulator session.
