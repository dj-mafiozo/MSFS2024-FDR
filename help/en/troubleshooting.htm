Troubleshooting and reporting a problem

Separate connection problems from file replay. An absent simulator can leave SimConnect waiting without invalidating offline playback. For a missing flight check group/search filters, index and MFZR existence. For a missing parameter check aircraft type and capture-time support. Report expected/actual behavior and relevant logs, reviewing them for personal information and keys before sharing.

Option / actionBehavior and limitations
Recording disabledCheck MSFS 2024, connection and Ready for flight. Preview deliberately disables capture.
Missing flightCheck filters, selected index and file existence; refresh/import. Back up before changing the index.
Missing instrument dataConfirm ICAO, display override and capture-time availability. A blank is not confirmed zero.
LayoutReset the layout; report monitor scaling/window arrangement if docking still fails.
AI failureCheck login/key/server/model, context and timeout; keep credentials out of shared logs.
Useful reportFull EXE and addon versions, steps, screenshots and relevant logs. Inspect recordings for personal data before sharing.
