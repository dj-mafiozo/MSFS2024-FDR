Settings guide

Settings are grouped into General, Units, Analysis, AI Engines, Debug and Ghost. Edit the relevant task options, then Save; Cancel retains previous settings. Presentation changes do not rewrite flight telemetry. If monitor changes leave windows offscreen or the layout becomes unusable, restore default docking rather than deleting recordings or the data directory.

Save applies displayed values; Cancel discards edits. Presentation settings never rewrite recorded telemetry.
