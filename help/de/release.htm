Portable-Veröffentlichungen und Changelog

Entpacken Sie das ganze ZIP mit Grafiken, Fonts und Hilfe. Schließen Sie vor Dateiaustausch die Anwendung. LocalAppData bleibt erhalten; sichern Sie es trotzdem. Beispiel-INI überschreibt keine persönliche INI. Setup ist nur Hinweis, Updates sind deaktiviert. Changelog nennt Releases, Build dient Diagnose.
