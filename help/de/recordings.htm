Aufnahmebibliothek, Import und Wiederherstellung

Sichern Sie die Quelle vor Import einer alten Datenbank oder einzelner MFZR. Migration erstellt je Flug eine Datei; der Index speichert Metadaten und relativen Pfad. Fehlende Dateien blenden den Flug aus, ohne den Eintrag zu löschen. Prüfen Sie den Speicherort. Text- und Gruppenfilter wirken gemeinsam.

Der Baum gruppiert ICAO-Flugzeugtyp, Abflug-ICAO, Jahr und lokalisierten Monat; neueste Flüge zuerst. Fehlende Dateien löschen keine Indexmetadaten.

Option / AktionVerhalten und Einschränkungen
Suche / GruppenText- und Gruppenfilter wirken zusammen. Zum Zurücksetzen leeren. Ein Ordner ist keine einzelne Aufnahme.
Öffnen / AktualisierenDatenbank/Index auswählen beziehungsweise Bibliothek neu laden und abgelegte .mfzr erkennen.
ImportEinzelne .mfzr, alte flight_data.db und ursprüngliche Qt-Datenbanken. Alte Flüge werden getrennte Dateien; Quellen bleiben erhalten, wiederholter Import erkennt vorhandene Einträge.
Legacy-ExportEin Flug mit den Feldern des ursprünglichen Recorders, ohne SDK/FMC/Wetter-Erweiterungen. Kein vollständiges Backup.
Gruppen / MetadatenGruppen erstellen, umbenennen, löschen und mit OK zuweisen. Fluginformationen bearbeiten die angebotenen Metadaten; Telemetrie bleibt separat.
Flug löschenBestätigung entfernt Datei und Indexeintrag. Laufende Aufnahme zuerst stoppen. Dies versteckt nicht nur eine Zeile.
WiederherstellungNach einem Absturz beim Start bestätigen. Das Ergebnis kann unvollständig/beschädigt sein; wertvolle Dateien vorher sichern.
EinzelvorschauEXE mit bestehendem .mfzr-Pfad starten: nur dieser Flug, ohne Bibliothek, Verwaltungs-/Aufnahmeaktionen oder SimConnect.
